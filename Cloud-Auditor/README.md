# Cloud Auditor

A Python CLI tool that finds unused cloud resources.

## Features

- Scan EBS Volumes
- Scan Elastic IPs
- Scan EC2 Instances
- Generate Reports
- Export JSON Reports
- Export CSV Reports
- Cleanup Resources

## Commands

Run Scan:

python main.py scan

Run Report:

python main.py report

Run Cleanup:

python main.py cleanup
